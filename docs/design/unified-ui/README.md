# 灵境智创统一 UI/UX 文字设计稿

## 1. 设计定位

本项目从“OpenAI 兼容网关后台”升级为“电商 AI 创作工作台”。视觉和交互不再以传统管理后台为中心，而是以创作任务、素材生成、结果交付为中心。

核心感受：

- 专业：保留后台系统需要的信息密度、状态反馈和可审计性。
- 轻盈：浅灰画布、白色面板、细边框、低阴影，避免厚重后台感。
- 明确：首屏必须告诉用户“从哪里开始创建任务”。
- 一致：首页、登录页、个人总览、电商工作台、资产库、后台配置使用同一套颜色、圆角、阴影和文字层级。

设计参考：

- DesignKit 的“AI 输入入口 + 工具货架 + 任务结果”结构。
- 现有 `docs/ui-prototypes/designkit-inspired/v3/prototype-v3-four-screens-board.png` 的浅色工作台方向。
- Element Plus 继续作为基础控件库，但通过项目 tokens 收口视觉气质。

## 2. 信息架构

### 个人端

个人端要突出“创作”和“用量资产”两类任务：

- 总览：账户状态、今日任务、最近生成、快捷入口。
- 在线体验：通用模型和图片体验。
- 电商智能体：统一的 AI 创作入口，默认显示大 Prompt 和场景切换。
- 商品图生成：从电商智能体拆出的图片任务能力。
- 商品短视频：视频生成、进度、错误日志和预览。
- 资产库：商品资产、模特资产、生成资产和复用。
- 任务记录：所有电商生成任务。
- API Keys、使用记录、账单与充值：保留平台能力，但视觉统一。

### 管理端

管理端仍保持高密度表格，但交互统一为“列表 + 右侧编辑面板”：

- 模型配置
- 上游渠道
- 用户与分组
- 充值与积分
- 电商平台
- 提示词模板
- 风格模板
- 电商资产审核
- 生成记录
- 系统设置

## 3. 设计系统

### 颜色

基础色：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--lc-bg` | `#F6F8FB` | App 主背景 |
| `--lc-bg-soft` | `#EEF4FF` | 首页浅色光感区域 |
| `--lc-surface` | `#FFFFFF` | 卡片、面板、弹窗 |
| `--lc-surface-soft` | `#F8FAFC` | 表格表头、输入区 |
| `--lc-border` | `#DDE5F2` | 主边框 |
| `--lc-border-soft` | `#E8EEF7` | 弱分割线 |
| `--lc-text` | `#101828` | 主文本 |
| `--lc-muted` | `#64748B` | 次级文本 |
| `--lc-subtle` | `#94A3B8` | 占位说明 |

品牌与功能色：

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--lc-primary` | `#2563EB` | 主按钮、选中态、关键进度 |
| `--lc-primary-strong` | `#1D4ED8` | hover / active |
| `--lc-primary-soft` | `#EAF1FF` | 菜单选中、浅蓝背景 |
| `--lc-mint` | `#14B8A6` | 电商创作、生成状态 |
| `--lc-mint-soft` | `#DDFBF6` | 电商能力浅底 |
| `--lc-amber` | `#F59E0B` | 排队、提醒 |
| `--lc-orange` | `#F97316` | 热门模板、营销强调 |
| `--lc-danger` | `#EF4444` | 失败、删除 |
| `--lc-success` | `#16A34A` | 完成 |

色彩比例：

- 70%：浅灰/白色画布。
- 20%：蓝色品牌操作。
- 8%：青绿色电商创作提示。
- 2%：橙/红/绿状态色。

避免：

- 大面积紫粉蓝渐变。
- 深蓝后台占据主视觉。
- 卡片左侧彩色竖条。
- 同一页面超过 4 个主色。

### 字体

字体族：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
```

层级：

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | `42px / 52px` | `700` | 首页主标题 |
| H1 | `28px / 36px` | `700` | 工作台页标题 |
| H2 | `20px / 28px` | `700` | 卡片组标题 |
| H3 | `16px / 24px` | `650` | 卡片标题 |
| Body | `14px / 22px` | `400` | 正文、表格 |
| Small | `12px / 18px` | `400` | 标签、说明 |
| Number | `24px / 32px` | `700` | 余额、统计数字 |

### 间距

采用 8px 网格：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--lc-space-1` | `4px` | 图标与文字 |
| `--lc-space-2` | `8px` | 标签、紧凑元素 |
| `--lc-space-3` | `12px` | 控件间距 |
| `--lc-space-4` | `16px` | 卡片内距 |
| `--lc-space-5` | `20px` | 区块内距 |
| `--lc-space-6` | `24px` | 页面内距 |
| `--lc-space-8` | `32px` | 大区块间距 |

### 圆角与阴影

圆角策略：

- 输入框、按钮：`8px`
- 普通卡片：`12px`
- 强调面板、Prompt 区：`16px`
- 顶层浮层：`18px`

阴影策略：

```css
--lc-shadow-card: 0 10px 30px rgba(15, 23, 42, 0.06);
--lc-shadow-popover: 0 18px 48px rgba(15, 23, 42, 0.14);
```

阴影只用于浮层和重点面板，普通卡片主要靠细边框和背景层次。

## 4. 关键组件

### App Shell

- 侧栏从深色后台改为浅色工具栏。
- 宽度：展开 `236px`，折叠 `72px`。
- 顶栏高度：`60px`。
- 菜单选中：浅蓝底、蓝色文字、左侧 3px 蓝色指示。
- 品牌区显示“灵境智创 / 电商 AI 工作台”，不要只显示 GPT2API。

### AI Prompt Composer

这是产品的首屏主组件：

- 面板圆角 `16px`。
- 文本输入最小高度 `128px`。
- 顶部用场景 segmented control：商品主图、商品短视频、Listing 文案、竞品调研、A+ 详情页。
- 底部操作区：上传图片、选择商品资产、选择模特资产、选择模板、开始生成。
- 生成按钮固定在右下角，视觉权重最高。
- 错误和缺参提示放在输入区下方，不用全局 toast 堆叠。

### 工具货架

用于工作台首页、总览页和模板中心：

- 每张卡片包含图标、标题、说明、最近状态。
- 卡片高度保持一致，桌面端 4 列，平板 2 列，移动端 1 列。
- hover 只改变边框、背景和轻微阴影，不做大幅位移。

### 任务进度

固定四段：

1. 提交
2. 排队中
3. 生成中
4. 完成

任务级错误用局部错误面板展示：

- 错误发生阶段
- 错误时间
- 可重试动作
- 原始错误摘要

不要用多个全局 toast 表示初始化失败。

### 资产画廊

- 商品图：4:3 或 1:1 缩略图。
- 商品短视频：9:16 预览。
- 操作用图标按钮：预览、下载、复制提示词、重试。
- 失败资产在卡片内展示错误摘要。

### 管理配置页

- 搜索筛选固定在顶部。
- 表格高密度，行高 `52px`。
- 新增/编辑使用右侧抽屉，宽度 `420px`。
- 模板类型使用 Tabs。
- 主操作按钮统一放在右上角。

## 5. 页面设计稿

### 首页

目标：从“API 网关营销页”改为“AI 电商创作入口”。

首屏结构：

- 顶部导航：品牌、在线体验、电商智能体、接口文档、登录/进入控制台。
- 左侧：一句话主张“电商 AI 创作工作台”。
- 中心：大 Prompt 输入框，模拟用户输入商品需求。
- 右侧：生成结果预览，包括商品图、短视频、Listing 文案。
- 首屏底部露出工具货架，暗示后续能力。

首屏文案：

- H1：`电商 AI 创作工作台`
- Sub：`把商品资料变成主图、短视频、Listing 文案和详情页结构。`
- CTA：`开始创建`、`查看演示`

### 登录 / 注册

目标：从普通后台登录页改为同一品牌的产品入口。

结构：

- 左侧展示工作台预览卡片：任务提交、排队、生成、交付。
- 右侧登录表单。
- 移动端隐藏复杂预览，但保留品牌和短价值说明。

### 个人总览

目标：从数据堆叠改为“今天能做什么 + 当前账户状态”。

首屏模块：

- 欢迎卡：账号、余额、今日消耗。
- 快捷动作：电商智能体、在线体验、资产库、账单充值。
- 近期生成：展示最近任务状态。
- 使用趋势：保留轻量图表。

### 电商智能体

目标：成为产品主工作台。

桌面端布局：

- 顶部：页面标题 + 场景切换 + 任务状态摘要。
- 左中：大 Prompt Composer。
- 右侧：当前任务进度 + 视频预览。
- 下方：资产画廊 + 文案输出 + 任务列表。

移动端布局：

1. Prompt Composer
2. 场景快捷入口
3. 当前任务进度
4. 资产画廊
5. 任务记录

### 资产库

目标：从普通 CRUD 表格升级为可复用素材中心。

结构：

- 顶部筛选：商品 / 模特 / 公共 / 私有 / 审核状态。
- 卡片视图优先，表格作为高级模式。
- 资产详情用右侧面板展示图库、标签、授权、使用记录。

### 后台配置

目标：保留效率，但视觉跟前台统一。

结构：

- 左侧主列表。
- 右侧编辑抽屉。
- 顶部标签切换模板类型。
- 表单说明使用局部帮助文本，不用大量提示块。

## 6. 响应式规则

- `>= 1280px`：三列工作台。
- `960px - 1279px`：两列工作台，右侧交付卡下移。
- `< 960px`：单列，Prompt Composer 必须在第一屏。
- `< 640px`：按钮满宽或 2 列图标按钮；表格转卡片或横向滚动。

移动端禁止：

- 首屏先显示空任务区。
- toast 遮住标题和主按钮。
- KPI 卡片过大导致信息密度极低。

## 7. 实施优先级

第一批：

1. 全局 tokens 和 Element Plus 变量覆盖。
2. BasicLayout 改为浅色工作台 shell。
3. 首页重写为 AI 电商创作入口。
4. 登录/注册统一品牌背景。
5. Dashboard 收口为工作台总览。
6. EcommerceWorkbench 改为 Prompt 优先。

第二批：

1. 资产库卡片视图。
2. 后台电商配置页右侧抽屉。
3. 所有列表页统一 toolbar/table/pagination。
4. 错误提示从全局 toast 改局部状态。

验收标准：

- 桌面和移动端首屏都能看出产品核心能力。
- 首页、登录、总览、电商工作台不再像四套产品。
- 主要交互元素有 hover/focus/loading/disabled 状态。
- 移动端无横向滚动，文字不溢出。
- 构建通过，浏览器截图无明显重叠和空白异常。
