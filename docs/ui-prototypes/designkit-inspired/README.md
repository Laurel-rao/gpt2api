## 组件规范

### 侧边菜单

- 宽度：展开 `220px`，折叠 `64px`。
- 菜单项高度：`44px`。
- 选中态：`#EAF1FF` 背景，文字 `#2563EB`，左侧可加 `3px` 蓝色指示条。
- 分组标题使用 `12px`、灰色，不参与主视觉抢占。

### Prompt 输入区

- 首页工作台的核心入口，宽度占主内容 `65% - 75%`。
- 面板圆角 `12px`，padding `24px`。
- 输入框最小高度 `112px`。
- 底部放快捷动作：粘贴商品链接、上传参考图、选择模板、生成。
- 生成按钮固定在右下角，按钮高度 `40px`。

### 场景快捷入口

使用 segmented control，而不是散乱按钮：

- 商品主图
- 商品短视频
- Listing 文案
- 竞品调研
- A+ 详情页

选中项使用蓝底白字，未选中项使用白底深色文字。

### 视频生成进度

固定四段：

1. 提交
2. 排队中
3. 生成中，展示百分比
4. 完成

状态映射：

| 本地状态 | 显示 | 颜色 |
| --- | --- | --- |
| `queued` | 排队中 | warning |
| `running` | 生成中 xx% | primary |
| `success` | 完成 | success |
| `failed` | 失败 | danger |
| `canceled` | 已中断 | muted |

错误日志需要独立展示，包含时间、阶段、错误内容、重试次数。

### 模板卡片

- 缩略图比例：图片模板 `4:3`，视频模板 `9:16` 或横向 `16:9`。
- 卡片圆角 `8px`，padding `12px`。
- 操作按钮固定：`预览`、`做同款`。
- 模板标签最多展示 3 个，超过折叠。
- 视频模板缩略图左下角展示时长，例如 `00:15`。

### 资产卡片

- 每张资产保留：类型、状态、缩略图、生成/排队耗时。
- 操作使用图标按钮：预览、下载、提示词、重试。
- 失败资产直接展示错误摘要，悬浮或展开可看完整日志。

### 后台配置页

- 列表 + 右侧编辑面板。
- 表格密度比前台更高，行高 `56px`。
- 右侧编辑面板宽度 `380px - 420px`。
- 表单行距 `12px`，面板 padding `20px`。
- 模板类型使用 Tabs：图片模板、视频模板、文案模板。

## 页面落地优先级

1. 商品短视频页面：先落分段进度、错误日志、9:16 预览、提示词结构字段。
2. 电商智能体首页：把任务创建改成大 Prompt + 场景切换 + 近期任务。
3. 模板中心：补“预览 / 做同款 / 套用提示词”链路。
4. 后台提示词模板：增加视频模板 Tab 和右侧编辑面板。
