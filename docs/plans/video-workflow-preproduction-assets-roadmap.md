# 视频工作流前期材料资产与路线图

## 目标

当前视频画布已经能把节点运行到图片、视频和成片，但默认预设仍偏“边跑边生成”。为了让 Seedance 类短剧出片更稳，内置预设需要先形成一套可审核、可复用的前期材料包，再进入角色图、背景图、视频片段和合成。

核心路线：

`故事大纲 -> 人物角色 -> 场景背景 -> 分集剧情 -> 分镜镜头 -> Seedance 提示词 -> 角色图/背景图 -> 15 秒视频 -> 时间线合成`

## 材料资产清单

| 资产 | 必填内容 | 来源节点 | 下游用途 | 验收点 |
| --- | --- | --- | --- | --- |
| 故事圣经 | 标题、类型、主题、记忆点、情绪弧线、禁用项 | `brief` | 全链路统一风格和边界 | 有明确冲突、反转和结尾情绪 |
| 人物小传 | 角色 ID、姓名、年龄、关系、动机、性格、表演方式、服装妆发 | `brief` / `script` | 角色定妆、视频角色参考 | 每个角色可单独生成设定图 |
| 场景设定表 | 场景 ID、地点、时间、空间布局、光影、道具、禁用项 | `brief` / `script` | 背景图生成、视频空间连续性 | 背景节点只拿环境信息，不混入人物动作 |
| 分集/分幕剧情 | 集数、幕名、剧情目标、冲突推进、转折、钩子 | `script` | 场景节点拆分 | 四幕互相推进，不是四个孤立场面 |
| 分镜镜头表 | 镜号、时间段、景别、运镜、构图、动作、表情、台词、音效 | `script` | 视频节点 Seedance prompt | 15 秒片段必须有 0-3、4-8、9-12、13-15 秒镜头 |
| Seedance 引用说明 | `@图片1` 背景、`@图片2` 女主、`@图片3` 男主、`@图片4` 表小姐 | `video` prompt | 多参考图语义绑定 | 每个 @ 引用必须说明用途 |
| 成片路线图 | 四段顺序、入出点、合成规格、交付物 | `timeline` / `compose` | 合成和验收 | 时间线 1-4 段、30fps、H.264/AAC |

## 预设适配规则

### 1. brief 节点

`brief` 不只保存一句创意，应保存结构化资产种子：

- `series_bible`：主题、类型、情绪曲线、记忆点。
- `character_bible`：三个主要角色的小传和视觉规范。
- `scene_bible`：四个场景的空间与光影规则。
- `episode_route`：四幕剧情目标和结尾钩子。
- `storyboard_contract`：镜头字段、时间段和 Seedance 词库范围。
- `seedance_contract`：`@图片` 引用、非写实真人、无字幕水印、中文提示词。

### 2. script 节点

`script` 输出必须是严格 JSON，顶层至少包含：

- `project`
- `characters`
- `locations`
- `episodes`
- `scenes`
- `seedance_prompt_contract`

其中 `scenes` 必须恰好四项，每项包含：

- `id`
- `episode_id`
- `title`
- `duration_seconds`
- `location_id`
- `dramatic_beat`
- `conflict`
- `emotional_turn`
- `dialogues`
- `shots`
- `audio`

`shots` 必须覆盖四个时间段：

- `0-3秒`
- `4-8秒`
- `9-12秒`
- `13-15秒`

每个镜头包含：

- `shot_id`
- `time_range`
- `景别`
- `运镜`
- `构图`
- `action`
- `expression`
- `lighting`
- `dialogue`
- `audio`
- `seedance_prompt`

### 3. 角色节点

角色节点读取人物小传，生成定妆参考图。角色图仍可以保留三视图和服装细节，但需要在 prompt 中明确：

- 这是“角色设定参考图”，不是剧情镜头。
- 视频节点使用时应以单个角色形象为参考，不把拼贴布局当成剧情画面。
- 禁止写实真人脸。

### 4. 背景节点

背景节点只读取场景设定中的环境信息，保留：

- 地点
- 时间
- 光影
- 空间布局
- 道具
- 氛围

必须丢弃：

- 角色动作
- 台词
- 表演
- 冲突描写
- 可辨识近中景人物

### 5. 视频节点

视频节点把场景 JSON 的 `shots` 转成 Seedance 原生提示词：

- 开头写 `9:16，30fps，15秒，二维国风动画短剧`。
- 明确 `@图片1` 到 `@图片4` 的用途。
- 使用时间戳分镜。
- 台词用引号，标角色和情绪。
- 使用词库中的景别、运镜、构图和声音词。
- 结尾写禁止项：不要字幕、LOGO、水印、写实真人脸、角色换脸。

## 路线图

### Phase 1：预设材料规范化

- 升级内置古风模板的 `brief`、`script`、角色、背景和视频 prompt。
- 模板版本提升，避免旧工作流与新材料契约混用。
- 测试断言模板包含人物小传、场景设定、分集剧情、分镜镜头和 `@图片` 引用规则。

### Phase 2：运行时结构校验

- 在 `script` 节点后校验 `scenes.length == 4`。
- 校验每个 `scene.shots` 覆盖四个时间段。
- 校验 `characters`、`locations`、`episodes` 不为空。
- 校验失败时阻断视频生成，提示用户修复分镜 JSON。

### Phase 3：UI 材料面板

- Inspector 增加“材料包”视图。
- 提供人物表、场景表、分幕剧情、分镜表的结构化查看与编辑。
- 分镜表支持按镜号编辑景别、运镜、台词和音效。

### Phase 4：Seedance 多模态增强

- 工作流级音频开关进入 Graph。
- 支持视频参考和音频参考端口。
- 支持 Draft 样片、离线推理、返回尾帧接龙等 Seedance 能力。
- 运行确认展示模型、音频策略、参考图数量和预计产物。

## 完成标准

- 新建古风预设时，用户能在工作流中看到正式的剧情脚本、人物角色、场景背景、分集剧情和分镜镜头材料。
- 每个视频节点 prompt 可直接复制到 Seedance 使用，并且包含 `@图片` 引用用途、时间戳分镜、台词、音效和禁止项。
- 工作流在进入视频生成前，能校验材料包结构，不再把“任意合法 JSON”当作可用分镜。
- 出片失败时，用户能定位是素材、分镜、模型配置还是上游额度问题。
