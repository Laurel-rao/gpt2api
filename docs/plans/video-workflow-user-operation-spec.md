# 视频工作流自动生成视频：用户操作逻辑与完成标准

复盘日期：2026-07-14

## 1. 文档目的

本文以实际代码为实现真值，梳理用户从进入视频工作流到取得最终 MP4 的全部操作、状态、异常和恢复路径，并区分：

- **已闭环**：界面入口、前后端处理、结果反馈和必要测试均有代码证据。
- **部分闭环**：底层能力存在，但用户入口、异常恢复或测试缺失。
- **未闭环**：API、工具函数或文档声称存在，但当前页面没有可完成操作的入口。

需求基线来自 `docs/plans/video-workflow-requirements.md`；验收声明来自 `docs/plans/video-workflow-verification.md`；问题细节同时引用 `docs/plans/current-worktree-implementation-review-20260714.md`。

## 2. 自动生成视频的完整用户闭环

功能完成后的标准主路径应为：

1. 管理员进入视频工作流页面。
2. 新建或选择工作流。
3. 选择画幅、分辨率、模型和审批策略。
4. 编辑故事、角色、剧本、场景、图片、视频节点及连线。
5. 上传或生成素材，确认角色和分镜；选择自动策略时无需人工停顿。
6. 配置 1–4 个时间线片段的顺序和裁剪范围。
7. 选择完整运行、当前节点或当前及下游，完成校验和费用确认。
8. 后端按不可变 revision 快照执行，前端持续展示排队、生成、审批、停止、成功或失败状态。
9. 失败后用户能定位失败节点并重试，已成功节点通过缓存复用。
10. 最终成片可预览、下载，并可从历史记录再次查看。
11. 刷新页面、断网、修订冲突或服务重启后，用户都有明确恢复路径。

当前实现已完成主干运行能力，但第 3、5、6、9、11 步仍存在用户操作断点，因此暂不能把“所有用户操作闭环”标记为完成。

## 3. 角色、入口与数据隔离

### 3.1 页面访问

**状态：已闭环**

- 前端路由 `/personal/video-workflows` 要求 `self:video_workflow` 且 `adminOnly`，见 `web/src/router/index.ts:35-39`。
- 菜单权限同样映射 `PermSelfVideoWorkflow`，见 `internal/rbac/menu.go:40-43`。
- 后端工作流、运行和素材接口均同时经过管理员与权限中间件，见 `internal/server/router.go:196-225`。
- DAO 和 Service 的工作流、运行、素材查询都携带当前 user ID；运行详情也按用户归属读取。

**用户结果**

- 有权限管理员：进入五区工作区。
- 无权限或普通用户：前端路由和后端接口均拒绝，不依赖菜单隐藏保障安全。

## 4. 工作流生命周期

### 4.1 首次进入和初始化

**状态：部分闭环**

页面并发加载模板、工作流列表、素材和模型，见 `VideoWorkflows.vue:918-923`：

- 模板、工作流主请求成功：选择第一模板并加载工作区。
- 素材或模型失败：局部降级为空列表，不阻断页面。
- 主请求失败：进入离线画布并显示本地草稿提示。

**缺口**

- 没有工作流时，页面仍显示示例名称和 starter graph，但运行只提示“请先从模板创建工作流”；缺少明确的新手空状态和单一主行动按钮。
- 模板为空时仅在创建对话框显示“服务端尚未提供可用模板”，没有刷新或诊断入口。

**完成标准**

- 零工作流状态只展示“创建第一个工作流”，不让示例画布被误认为已保存工作流。
- 模板加载失败与模板真实为空使用不同文案，并提供重试。

### 4.2 新建工作流

**状态：已闭环**

用户点击页头“新建工作流”：

1. 输入最长 40 字名称。
2. 选择服务端模板。
3. `createVideoWorkflow()` 调用 `POST /api/me/video-workflows`。
4. 后端克隆模板 Graph，创建 revision 1。
5. 新项加入下拉列表并立即加载详情。

代码：`VideoWorkflows.vue:1148-1156、2660-2676`，`web/src/api/videoWorkflow.ts:308-317`，`internal/videoworkflow/service.go:115-138`。

**边界**

- 名称为空时前端函数直接返回；创建按钮只按模板禁用，未按空名称禁用。
- 创建请求失败主要依赖全局 HTTP 提示，页面没有字段级错误。

### 4.3 选择和切换工作流

**状态：已闭环**

- 下拉框支持名称过滤。
- 正在“运行准备”时阻止切换。
- dirty 草稿切换前最多尝试 4 次保存；失败则保留当前工作流。
- 成功后通过工作区世代隔离旧异步结果。

代码：`VideoWorkflows.vue:1030-1035、1159-1164、2451-2457`。

### 4.4 重命名工作流

**状态：部分闭环**

重命名通过完整工作流 PUT 完成；后端以 revision 乐观锁更新名称和 Graph。

**已确认断点**

- 重命名请求没有进入 `activeSavePromise` 保存队列。
- 自动保存与重命名可携带同一 revision 并发，后到请求返回 409。
- catch 把取消、网络错误和 revision 冲突全部当作取消静默吞掉。

证据：`VideoWorkflows.vue:985-1027、1166-1196`，`internal/videoworkflow/dao.go:158-182`。

**完成标准**

- 重命名前先完成在途保存，名称更新与 Graph 保存共用同一串行队列。
- 取消不提示；网络错误提示重试；409 进入统一冲突处理。

### 4.5 删除工作流

**状态：未闭环**

- 前端 API 已定义 `deleteVideoWorkflow()`，见 `web/src/api/videoWorkflow.ts:320-322`。
- 后端 DELETE 路由、Handler、Service、DAO 均已实现，见 `internal/server/router.go:205`、`internal/videoworkflow/handler.go:110-116`。
- 当前 `VideoWorkflows.vue` 没有导入或调用该 API，更多菜单也只有大纲、导入和导出。

**完成标准**

- 工作流菜单提供删除入口。
- 删除前展示名称、运行历史/素材不随工作流删除的边界。
- 活跃运行或运行准备期间禁止删除。
- dirty 草稿明确选择取消、先保存或放弃。
- 删除成功后切换到下一工作流；无剩余项时进入首次创建状态。

## 5. 画布导航和布局操作

### 5.1 工具切换与视口

**状态：已闭环**

- 选择工具 V、抓手 H/空格、连线工具。
- 滚轮平移，修饰键缩放，触控板 pinch 缩放。
- 放大、缩小、100%、适应全部和适应选中。
- 小地图点击、拖动及键盘方向导航。
- 视口变换只属于展示状态，不写入 Graph。

代码：`VideoWorkflowCanvas.vue:174-230、242-315、338-358`，`VideoWorkflows.vue:2308-2332`。

### 5.2 侧栏

**状态：桌面已闭环，窄屏未定义**

- 左侧节点/素材库和右侧 Inspector 可折叠、恢复、拖动宽度。
- 宽度、开关、连线模式和自动排布写入 localStorage。
- 1280px 以下媒体查询隐藏两侧面板和恢复按钮。

代码：`VideoWorkflows.vue:2362-2397、2505-2621、2717-2720`。

**完成标准**

- 产品若仅支持桌面，应在路由入口给出最小宽度说明。
- 若要求平板可用，必须提供抽屉式节点库和 Inspector 入口。

### 5.3 自动布局

**状态：已闭环**

- 整理自动节点。
- 所选节点恢复自动布局。
- 确认后重新整理全部未锁定节点。
- 自动排布开启后监听节点/边结构并防抖 480ms。
- ELK 失败时回退 dagre。
- 布局期间发生新编辑，旧结果不写回。

代码：`VideoWorkflows.vue:1631-1712`，`videoWorkflowElk.ts:47-115`，`videoWorkflowLayoutEngine.ts`。

### 5.4 对齐、分布、锁定、折叠和分组

**状态：已闭环**

- 左对齐、顶部对齐、水平/垂直等距分布。
- 锁定节点后拖动和键盘移动不写回。
- 折叠改变节点尺寸并重算布局边界。
- 至少两个节点可写入同一 `canvas_group_id`；可解除分组。
- 手工移动后节点切为 `position_mode=manual`。

代码：`VideoWorkflows.vue:1714-1775`。

## 6. 节点操作

### 6.1 搜索、添加和拖放

**状态：已闭环**

- 节点库按中文标签过滤。
- 点击节点类型在默认位置新增。
- 拖到画布时使用 `screenToFlowCoordinate()` 放置。
- timeline 和 compose 为固定系统节点，不能重复新增。
- 节点总数、边总数、角色节点数均有前端上限。

代码：`VideoWorkflowLibrary.vue:34-55、84-107`，`VideoWorkflows.vue:1271-1290`。

**缺口**

- Graph 节点定义和模板包含 `scene` 类型，但 `VIDEO_WORKFLOW_NODE_CATALOG` 没有 scene；用户删除场景描述节点后无法从节点库重新添加，只能撤销、导入 JSON 或重建工作流。

### 6.2 选择

**状态：已闭环**

- 单击单选，Shift 增减多选，框选同步多选集合。
- 框选完成后同步 Inspector 当前节点，避免参数修改作用于旧节点。
- 点击空白清空所有节点和边选择。
- 结构大纲选择节点后关闭大纲并定位节点。

代码：`VideoWorkflows.vue:1198-1269`，`VideoWorkflowOutline.vue:12-24`。

### 6.3 参数编辑

**状态：部分闭环**

Inspector 已支持：

- 节点名称。
- 通用 prompt。
- 视频执行模型。
- 角色姓名和成年年龄。
- 节点状态、进度、运行次数、缓存、消耗、输入哈希和错误。
- 上游输入查看及键盘方式添加/替换连接。

代码：`VideoWorkflowInspector.vue:252-410`。

**缺口**

- `adult_age` 输入虽有 HTML min/max，但直接把 Number 写入 Graph；前端 Graph 校验没有年龄范围规则，服务端节点业务校验是否拒绝需依赖运行阶段。
- scene、video、compose 等节点的实际可配置业务参数没有统一 schema，Inspector 主要展示固定值。
- Graph 已支持角色/分镜审批策略，页面没有入口。

### 6.4 复制、粘贴、撤销和删除

**状态：已闭环**

- Cmd/Ctrl+C、V、D。
- 粘贴只保留所选节点内部边，并逐条重新校验。
- undo/redo 各保留最近 50 个 Graph 快照。
- 删除前分析下游影响；timeline/compose 不可删除。
- 删除后显示 5 秒撤销 toast。
- 删除视频同步移除时间线片段。

代码：`VideoWorkflows.vue:939-977、1365-1464、2308-2350`。

## 7. 连线操作

### 7.1 Handle 直连和反向拖动

**状态：已闭环**

- Vue Flow 使用 Loose 模式。
- 正向 output→input 保持原方向。
- 反向 input→output 自动交换。
- 连接前校验节点、端口、类型、重复、单值输入和环。
- 单值输入已有连接时要求确认替换。

代码：`VideoWorkflowCanvas.vue:275-315`，`videoWorkflowGraph.ts:784-851`，`VideoWorkflows.vue:1502-1527`。

### 7.2 拖到节点主体或空白

**状态：部分闭环**

- 拖到节点主体时按类型寻找兼容输入。
- 拖到空白时打开“创建兼容节点”菜单。
- Inspector 可从所有兼容输出中选择并添加连接。

**缺口**

- 节点主体自动选端口不优先空闲端口。
- TouchEvent 被当作 MouseEvent 读取坐标。
- 无可见端口时可能回退到 smart 模式隐藏端口，缺少明确规则。

代码：`VideoWorkflows.vue:1529-1610、2006-2018`。

## 8. 素材操作

### 8.1 素材列表和选择

**状态：部分闭环**

- 初始化读取前 100 个素材；运行后刷新和缺失绑定恢复会按每页 100 个继续拉取，最多 1000 个。
- 素材库支持名称搜索、图片/视频缩略展示。
- 图片节点可进入“从素材库选择”模式。
- 选择图片后更新节点素材 ID、版本 ID、预览和变换基线，并把下游标记 stale。
- 视频上传或工作流生成完成后，后端尝试通过 FFmpeg 抽取首帧 JPEG sidecar；素材列表和节点卡使用该图片作封面，全屏播放另行签发原视频 URL。抽帧失败只记录日志，不阻断视频素材创建。

代码：`VideoWorkflows.vue:399-425、1862-1891`，`internal/videoworkflow/asset_service.go:126-242、340-367`，`internal/videoworkflow/composer.go:205-248`。

**缺口**

- 首次打开仍只加载 100 个素材，且素材库没有显式分页/“加载更多”；只有后续 `refreshAssets()` 才会补拉到 1000 个。
- API 已有素材删除，但页面无删除入口。
- 视频素材可展示，但当前 Graph 操作没有把视频素材绑定到视频/时间线节点的用户路径。

### 8.2 上传

**状态：未闭环**

节点库上传控件允许 JPEG、PNG、WebP、MP4、WebM、MOV，文案为“上传图片或视频”，见 `VideoWorkflowLibrary.vue:110-117`。实际父级处理 `replaceImage()`：

- 没有选中节点时直接返回，不会上传。
- 上传后只允许 `asset.kind==='image'` 绑定到当前节点。
- 上传视频时素材可能创建成功，但节点绑定无动作，仍提示“图片已上传为新素材版本”。
- 选中非图片节点时也会把图片字段写入该节点。

证据：`VideoWorkflows.vue:1852-1891`。

**完成标准**

- “素材库上传”必须独立于当前节点，上传成功后始终进入素材列表。
- “节点上传替换”只接受与节点兼容的 kind。
- 视频上传要么支持绑定视频节点/时间线，要么从素材库入口移除视频格式和误导文案。
- 上传过程显示进度、文件大小/格式错误和最终素材状态。

### 8.3 素材删除

**状态：未闭环**

- `deleteVideoAsset()` 和后端 DELETE 已实现。
- 当前素材卡片没有删除、引用提示或失败恢复入口。

**完成标准**

- 删除前显示被哪些节点引用。
- 已引用素材禁止删除或要求先解除绑定；具体规则与后端一致。
- 删除成功后刷新列表，当前选中节点若受影响则标 stale。

## 9. 图片生成、版本与变换

### 9.1 上传替换和重新生成

**状态：已闭环**

- 图片节点可上传替换、选择素材或运行节点生成。
- “重新生成”先获取费用确认，再清除旧绑定、保存新 revision、重新估价并提交。
- 任一步失败会回滚原 Graph 并再次保存。

代码：`VideoWorkflows.vue:1993-2004、2033-2128`，`videoWorkflowRunTransaction.ts`。

### 9.2 裁剪、旋转、翻转和重置

**状态：已闭环**

- 变换以节点为串行队列，避免同节点并发覆盖。
- 先确保节点存在真实素材绑定。
- 服务端创建不可变新版本。
- 返回前再次核对工作区世代、素材 ID、版本 ID、基线版本和变换快照，旧异步结果不会覆盖新选择。
- 成功后更新版本、预览并标记下游 stale。

代码：`VideoWorkflows.vue:1893-1962`，`VideoWorkflowInspector.vue:370-391`。

### 9.3 版本切换和预览

**状态：已闭环**

- Inspector 展示远端素材版本。
- 选择版本会恢复该版本对应的变换基线。
- 全屏预览优先签发当前素材版本 URL；签发失败时允许旧直链回退。
- 工作区切换或关闭弹窗会使旧预览异步结果失效。

代码：`VideoWorkflows.vue:393-531、1964-1991`。

## 10. 时间线操作

### 10.1 当前可执行操作

**状态：部分闭环**

- 视频节点可“添加到顺序时间线”。
- 最多 4 个片段，同一视频不能重复添加。
- 停用视频节点会移出时间线；重新启用时在容量允许时重新加入。
- 删除视频节点会移除对应片段；5 秒撤销会尝试恢复。
- `setTimelineClips()` 每次按 clips 全量重建时间线输入端口和边。

代码：`VideoWorkflows.vue:1777-1850`。

### 10.2 排序和裁剪

**状态：未闭环**

- 工具函数 `moveTimelineClip()`、`updateTimelineClipTrim()` 和相关单元测试存在。
- Graph 和后端支持 100ms 对齐、1000–15000ms 片段长度。
- 当前页面和 Inspector 没有调用这两个工具函数；时间线节点只显示片段数量与总时长。
- `web/e2e/video-canvas/fixtures.mjs` 直接预置 1200–12000ms 裁剪数据；契约测试只读取固定数据，没有执行用户排序或裁剪操作。

证据：`videoWorkflowGraph.ts:320-357、874-880`，`VideoWorkflowInspector.vue:394-401`，全仓调用搜索只在测试中发现排序和裁剪函数。

**文档冲突**

- `video-workflow-requirements.md:9` 把“单轨 1–4 段排序及 100ms 入出点裁剪”标记 done。
- `video-workflow-verification.md:11` 声称浏览器时间线排序恢复通过。
- 当前代码没有对应用户入口，需求状态应回刷为 partial。

**完成标准**

- timeline Inspector 显示 1–4 个片段。
- 支持拖动排序、移除、播放预览、输入或拖动 trim in/out。
- 每次裁剪按 100ms 吸附，最短 1000ms，最长 15000ms。
- 总时长实时计算，边与 clip 始终一一对应。
- 排序、裁剪、删除均进入 undo/redo、dirty 和自动保存。
- 增加组件测试和真实浏览器操作测试，不能只验证预置 fixture。

## 11. 全局生成参数

### 11.1 画幅和分辨率

**状态：已闭环**

- 页头支持 9:16、16:9、1:1。
- 分辨率支持 720p、1080p。
- 修改后标 dirty 并保存到 Graph revision。
- 前后端完整校验限制值域。

代码：`VideoWorkflows.vue:2463-2464`，`videoWorkflowGraph.ts:668-690`，`internal/videoworkflow/graph.go:120-140`。

### 11.2 模型

**状态：部分闭环**

- 管理端维护画布激活模型。
- 工作区加载模型列表。

**缺口**

- 管理端允许清空多选，但后端会静默恢复默认模型。
- 页面没有明确显示模型对应渠道、可用状态或探测结果。
- 模型配置变化后，已打开工作区只在重新加载时获取新列表。

### 11.3 审批策略

**状态：未闭环**

Graph 和 runtime 已支持：

- 角色：`manual` / `auto_first`。
- 分镜：`manual` / `auto`。

模板默认强制写为 manual，见 `internal/videoworkflow/template.go:137-166`；当前工作区没有编辑两个字段的控件。

新增 `scripts/local-workflow-smoke.mjs:67-75` 会绕过 UI，直接把 Graph 改为 `auto_first/auto` 再运行；这证明后端全自动链路可执行，也进一步证明缺口位于用户配置入口。

**影响**

用户无法从界面选择真正“不停顿”的自动生成流程；完整运行会在角色和分镜阶段两次等待人工操作。

**完成标准**

- 工作流设置提供“人工确认”和“全自动”预设，也允许分别配置角色与分镜。
- 切到自动策略时说明将自动选择第一张角色候选并直接采用生成分镜。
- 策略进入 Graph hash、费用估算和不可变运行快照。

**状态：系统配置存在，工作流用户不可配置**

**完成标准**

- 若仅全局控制，运行确认中展示当前音频策略，避免用户无法判断输出预期。

## 12. 启动运行

### 12.1 三种运行模式

**状态：已闭环**

- 完整运行：全部 active 节点。
- 当前节点：当前节点及所需上游。
- 当前及下游：起点下游闭包，并为每个下游补齐上游。

前端入口：页头 split button、Inspector“运行此节点”、Cmd/Ctrl+Enter，见 `VideoWorkflows.vue:2033-2128、2467-2481`。

后端选择逻辑：`internal/videoworkflow/runtime.go:715-783`。

### 12.2 保存和双重校验

**状态：部分闭环**

运行前：

1. dirty Graph 先保存。
2. 前端本地校验。
3. 服务端再次校验持久化工作流。
4. 估价。
5. 用户确认。
6. 确认期间 Graph/revision 变化则中止。
7. 携带 revision 和 estimate token 提交。

代码：`VideoWorkflows.vue:2043-2083`。

**缺口**

- 前端完整校验漏掉时间线 clip 与实际边的对应关系，可能本地通过、服务端失败。
- `validateVideoWorkflow(id, graph)` 前端发送当前 Graph，但后端 `Handler.ValidateWorkflow` 不读取请求体，只校验数据库已保存 Graph；当前正常运行路径依赖前置 `flushSave()` 才保持一致，接口契约本身存在误导。
- 校验只展示第一条错误；用户需要逐次修复后重新运行才能发现下一条。

**完成标准**

- 提供可点击的问题列表，按节点聚合全部错误。
- 前后端校验规则以契约测试保持一致。

### 12.3 费用确认与余额

**状态：部分闭环**

- 运行确认显示预计总积分；组件支持展示 `cached_credits`。
- estimate token 绑定用户、revision、Graph hash、模式、起点和过期时间。
- 服务端执行预留、实际结算与退款；失败和部分成功按实际节点成本结算。
- request ID 在本地保留 10 分钟，网络重试不会重复创建相同目标运行。

代码：`VideoWorkflowRunConfirm.vue:5-20`，`VideoWorkflows.vue:2020-2031、2057-2082`，`internal/videoworkflow/runtime.go`、`service.go`。

**缺口**

- 后端 `CostEstimate` 只有角色、场景和总积分，没有 `cached_credits`；生产接口不会提供前端支持的“缓存节省”值。

### 14.1 停止

## 15. stale 状态

### 15.1 当前逻辑

**状态：部分闭环**

- 修改参数、模型、图片版本或素材时标记当前及下游 stale。
- 运行启动时记录 stale 世代。
- 轮询只清除运行启动前已有、且本轮成功完成的 stale。
- 运行启动后的再次编辑不会被旧运行结果清除。

### 15.2 刷新恢复断点

**状态：未闭环**

加载工作区会清空 `nodeStaleEpoch`，但 Graph 中持久化的 stale 状态仍存在；运行成功后轮询遇到“没有本地世代”的 stale 会跳过。因此刷新页面后再运行成功，节点仍可能永久显示“需更新”。

证据：`VideoWorkflows.vue:792-800、2168-2179`。

**完成标准**

- 加载时为所有持久化 stale 建立基线集合或世代。
- 成功运行只清除本轮覆盖的 stale 节点。
- 刷新前后行为一致，并有自动化测试。

## 16. 自动保存、离线和修订冲突

### 16.1 自动保存

**状态：已闭环**

- 编辑后 800ms 防抖保存。
- 在途保存串行化。
- 保存期间继续编辑时，旧快照成功后安排下一次保存。
- 每次 PUT 以 revision 乐观锁推进 revision+1。
- 离线时保留 localStorage 草稿并每 5 秒重试。

### 16.2 页面离开

**状态：已闭环**

- beforeunload 写本地草稿。
- dirty 时触发浏览器离开确认。
- 组件卸载停止轮询和定时器。

### 16.3 修订冲突

**状态：未闭环**

409 时：

- `revisionConflict=true`。
- Graph 保存到 `.conflict` 本地键。
- Canvas 显示“恢复草稿”。

恢复按钮把冲突 Graph 放回画布并调用 `markDirty()`，但没有清除 `revisionConflict`。`saveWorkflow()` 和 `scheduleSave()` 在冲突为 true 时都直接返回；提示“请核对后保存”与实际不可保存矛盾。`reloadWorkflow()` 可以清冲突，但当前页面没有调用入口。

证据：`VideoWorkflows.vue:777-789、979-1027、1038-1042`。

**完成标准**

- 冲突栏提供“加载服务器版本”“导出本地草稿”“覆盖/另存为新工作流”。
- 恢复草稿后必须基于最新服务器 revision 合并或明确覆盖策略。
- 用户能从冲突状态退出，且不会静默丢任一版本。
